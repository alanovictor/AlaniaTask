Alania Task — Política de Privacidade

O Alania Task é um aplicativo de tarefas de uso pessoal, sem venda de dados, anúncios ou rastreamento.

Dados guardados

Tarefas, áreas, projetos, preferências e inscrições de notificação ficam no banco de dados do próprio app (Supabase), acessíveis apenas pela conta dona deles.

Google Tasks

Se você conectar o Google Tasks, o app usa somente a permissão de tarefas do Google para criar, concluir e apagar, na sua lista padrão, as tarefas do seu dia, e para ler a conclusão dessas mesmas tarefas. Nenhum outro dado da sua conta Google é acessado. O token de acesso fica guardado de forma restrita no servidor e é apagado quando você desconecta em Configurações.

O uso das informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Exclusão

Ao desconectar o Google Tasks o vínculo é removido; você também pode revogar o acesso em myaccount.google.com/permissions.
